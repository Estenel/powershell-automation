# PowerShell Automation

## Overview

Collection of PowerShell scripts used for IT administration, automation and system management tasks in Windows and Microsoft 365 environments.

---

## Example Use Cases

* User management automation
* Active Directory tasks
* Microsoft 365 health checks
* Log analysis
* Backup validation scripts
* System inventory collection

---

## Focus Areas

* Security automation
* Standardization of repetitive IT tasks
* Reducing manual administrative workload
* Improving operational efficiency

---

## Technologies

* PowerShell 5/7
* Active Directory module
* Microsoft Graph API (conceptual usage)
* Windows Server environments
